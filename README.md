> I asked the bank for a loan to open an escape room; they said no, so I locked the door and started the demo.

Character count: 108 (limit 1–200, single line, English)

## About the joke

A rejected entrepreneur turns bank robber on the spot — but he still calls
the heist a "demo". The polite startup pitch never leaves him, even while
he commits the crime. The punchline lands on "demo": the one word that
reframes a robbery as a product pitch.

## Run it

```bash
python3 main.py
```

Writes the entry line to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt` if set), with no trailing newline.
